# BetterMacNet Homebrew Tap

```sh
brew install bettermacnet/tap/bmtop
brew install --cask bettermacnet/tap/better-monitor
```

Formulae:

| Formula | Description |
|---------|-------------|
| [bmtop](https://github.com/BetterMacNet/bmtop) | Local-first macOS terminal monitor with native Apple Silicon SoC metrics |

Casks:

| Cask | Description |
|------|-------------|
| [better-monitor](https://github.com/BetterMacNet/better-monitor) | System monitor for processes, ports, network, startup items and local AI |
